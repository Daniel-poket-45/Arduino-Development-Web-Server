# Arduino WEB server
A very simple web server to manage projects and compile code for arduino boards

# Before running or compiling, please execute:
```sh
sudo apt-get update && sudo apt-get install emscripten -y
```

# WARNING!!! ALL BINARIES COMPILATED HERE IS WASM ARCHITECTURE!!!
